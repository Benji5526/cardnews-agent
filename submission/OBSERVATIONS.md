# OBSERVATIONS

질문·재개·실패 경로 검증 기록 (2026-10-23). 칸: 입력·조작 / 기대 결과 / 실제 결과 / 수정 후 결과 / 확인 방식.
"질문 대기 작업"은 실제 조사로 만든 작업을 복제해 편집 단계로 되돌린 **테스트용 복제본**이다(질문·근거는 실제 엔진 결과, 대기 상태 자체는 복제로 만듦).

| # | 입력·조작 | 기대 결과 | 실제 결과 | 수정 후 결과 | 확인 방식 |
|---|---|---|---|---|---|
| 1 | 독자·형식 질문 화면에서 새로고침 | 같은 프로젝트의 질문·선택지가 남고, 답변 전 제작이 시작되지 않음 | 작업 단계와 질문은 유지됨. 단, 체크·라디오·직접 입력·카드 수 같은 **미제출 선택은 사라짐** | 선택을 브라우저에 임시 저장해 새로고침 뒤 복원(라디오 선택, 직접 입력 문구, 카드 수 6 복원 확인). 4초 뒤에도 `busy=null`, 스토리보드 없음 | 브라우저(실제 화면)에서 새로고침. 질문은 실제 엔진 결과 |

## 확인하지 못한 것

- 엔진 교체(다른 엔진에 저장된 맥락을 넘기는 것)는 구현하지도 시험하지도 않았다. Claude CLI 하나만 연결했다.
- 2번의 "수정 전" 동작은 코드 검토 결과이고 실제로 재현해 보지 않았다.
