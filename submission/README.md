# 카드뉴스 에이전트 (학습일지 확장 포함)

주제나 메모를 입력하면 자료를 조사하고, 사용자의 선택을 받아 카드뉴스(또는 블로그 포스트 + 요약 카드)를 만드는 로컬 웹 앱이다. 조사·원고는 Claude Code CLI, 이미지는 agy(Antigravity CLI) 또는 Gemini API가 맡는다.

- 모드 1 **최신 소식 카드뉴스**: "AI 최신소식" → 최근 7일 후보 7~12건 → 선택 → 심층 검증 → 카드 5~8장
- 모드 2 **학습일지 → 블로그 포스트 + 요약 카드**: 오늘 공부한 메모 → 개념 후보 → 선택 → 원문 대조 → `post.md` + 카드 3~8장
- 모드 3 **호주 데일리 뉴스**: 시드니 기준 최근 24시간의 호주 큰 뉴스 3~4건을 한국어로 요약 번역해 한 편(5~6장)으로 자동 제작 → 사람이 검수·승인 (`npm run daily`)

## 준비

| 필요한 것 | 확인 |
|---|---|
| Node 24 이상 | `node -v` |
| Claude Code CLI(로그인 상태) | `claude --version` — 조사·원고 작성에 사용(웹 검색·원문 읽기만 허용) |
| 이미지 작업자 하나 | agy(설치·로그인) 또는 Gemini API 키 |

## 실행

```bash
npm install
cp .env.example .env     # 필요한 값만 채운다 (아래 표)
npm start                # http://localhost:4310
```

브라우저에서 `http://localhost:4310`을 열고, 첫 화면에서 모드를 고른 뒤 주제(와 학습일지는 메모)를 입력한다.

## 환경변수 (.env)

| 이름 | 설명 | 기본값 |
|---|---|---|
| `PORT` | 서버 포트 | 4310 |
| `GEMINI_API_KEY` | Gemini 이미지용 키. 무료 등급은 이미지 모델 한도가 0일 수 있다 | 없음 |
| `GEMINI_IMAGE_MODEL` | Gemini 이미지 모델 | gemini-2.5-flash-image |
| `IMAGE_WORKER` | `agy` / `gemini` / `auto` | auto |
| `AGY_ALLOW_ALL_TOOLS` | `1`이면 agy 실행의 모든 도구 요청을 자동 승인(빈 작업 폴더에서만 실행). **켜기 전에 DECISIONS.md의 권한 절을 읽을 것** | 꺼짐 |
| `AGY_BIN` | agy 실행 파일 경로 | `D:\Tools\agy\bin\agy.exe` 또는 PATH의 `agy` |
| `CLAUDE_BIN` / `CLAUDE_MODEL` | Claude CLI 경로 / 모델 | claude / sonnet |

이미지 작업자를 쓸 수 없으면(키·권한 없음) 카드는 대체 그라디언트 배경으로 진행하고 "실제 이미지 생성 미완료"로 기록한다. 상단의 "이미지 1장 테스트"로 연결을 먼저 확인할 수 있다.

## 매일 실행하기 (호주 데일리 뉴스)

```bash
npm run daily
```

서버가 꺼져 있으면 켜고, 오늘의 작업을 만든 뒤 주소를 알려 주고 돌아옵니다. 약 5~10분 뒤 그 주소(`http://localhost:4310/#작업ID`)에서 번역과 사실을 확인하고 승인한 뒤 내려받으세요. 외부에 게시하지 않습니다.

- 하루에 한 번 자동으로 실행하려면 Windows 작업 스케줄러에 등록합니다(아래는 예시이며 **이 저장소가 대신 등록하지 않습니다**). PC가 켜져 있어야 실행됩니다.

```bash
schtasks /Create /SC DAILY /ST 08:00 /TN "AuNewsDaily" /TR "cmd /c cd /d D:\Projects\cardnews-agent && npm run daily"
```

- 기사 사진은 저작권 때문에 쓰지 않고 단색 배경을 씁니다. 카드는 기사 전문 번역이 아니라 요약 번역과 출처 표기이며, 공개 게시 전에 매체별 이용 조건과 번역·인명 표기를 직접 확인하세요.

## 사용 흐름

1. 입력 → (뉴스) 최근 7일 후보 / (학습일지) 개념 후보. 자료가 부족하면 부족한 점을 표시한다.
2. 후보 1~3개 선택 → 심층 검증(확인한 사실 / 발표 주체의 주장 / 아직 확인하지 못함, 사용 조건, 자료 간 불일치).
3. 독자·형식·표지 문구 선택(이미 적은 편집 방향은 다시 묻지 않음) → 후킹 설계 → 스토리보드 승인.
4. 이미지·글자 제작 → 검수·카드별 수정 → 최종 승인 → ZIP 내려받기(내보낸 파일 점검 포함).

진행 중에는 "작업 진행 내역"에서 실제 검색어와 읽은 원문 주소를 볼 수 있다. 새로고침·서버 재시작 뒤에도 `data/jobs/<id>/job.json`에서 이어진다.

## 알려진 한계

- **보안:** 로컬 전용(127.0.0.1)이며 로그인이 없다. 다른 웹페이지의 접근은 막지만(Host·Origin 검사, CSP) 같은 PC의 다른 사용자는 막지 못한다. `AGY_ALLOW_ALL_TOOLS=1`은 프롬프트 주입에 완전히 안전하지 않으니 별도 계정·샌드박스가 없으면 켜지 말 것(DECISIONS.md "보안 점검과 조치").

- 이미지 생성이 막힌 상태(agy 한도·Gemini 무료 한도 0)에서도 CC0 사진으로 카드를 채울 수 있다.
- Gemini 무료 등급에서는 이미지 모델 한도가 0이라 생성되지 않았다. agy는 도구 자동 승인 옵션이 있어야 파일이 만들어졌다.
- 모델 응답 형식이 가끔 깨진다. 괄호·따옴표 보정과 1회 자동 재시도를 넣었지만 모든 경우를 막지는 못한다.
- 엔진 교체와 라이선스 스톡(Pexels 등) 이미지는 구현하지 않았다. CC0·퍼블릭 도메인은 Wikimedia Commons에서 카드별로 직접 골라 쓸 수 있다(검수 단계의 "CC0·퍼블릭 도메인 사진으로 바꾸기"). (두 프로젝트 동시 실행은 시험해 섞이지 않음을 확인했다. OBSERVATIONS.md 6번)
